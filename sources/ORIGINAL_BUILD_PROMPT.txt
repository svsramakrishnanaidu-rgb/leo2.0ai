MANDATORY MOBILE POLICY:
- An overlay grants display capability, not unlimited screen reading.
- MediaProjection requires active OS consent per session; release on stop.
- Avoid autonomous cross-app control via AccessibilityService. Google Play
  prohibits ordinary agents using Accessibility APIs to autonomously plan
  and execute actions; prefer system intents, OAuth and visible user action.
- Never bypass sandboxing, screen security, auth dialogs or protected data.
- Require previews and fresh approval for deletes, financial operations,
  messages, postings, account/security changes and irreversible actions.
- Explicit stop, revoke, privacy status and audit history always visible.
